# Open-source value standard

The public edition is the complete local product, not a crippled acquisition tier.

## Permanent public commitments

- Framework-neutral schema and adapter-authoring API
- Local collection, durable storage, query, inspection and export
- Core maintained adapters and OpenTelemetry interoperability
- Privacy controls, redaction, diagnostics and security fixes
- Unlimited local traces within user-owned resources
- Documented data formats and migration tooling
- No account, cloud connection or product telemetry requirement

## Enterprise value boundary

Enterprise earns revenue through managed scale, shared operations, governance and support: multi-user organizations, hosted retention, cross-project analytics, alerting, identity, audit, policy enforcement, private deployment and contractual service levels.

Features must not move from public to enterprise merely to increase conversion. Any boundary change requires an RFC, migration analysis, trust review and public changelog entry.

## Quality bar

A public feature is not complete until it has typed APIs, safe defaults, configuration documentation, compatibility policy, failure behavior, tests, package verification and an operator-visible diagnostic path. Adoption metrics never override security, portability or correctness gates.
